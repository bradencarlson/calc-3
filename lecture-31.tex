\subsection{The Fundamental Theorem for Line Integrals}

\content{

}{% presentation
\vspace{2in}
}{% nopresentation
}{% comments
Recall the fundamental Theorem of Calculus
}

\content{
\begin{theorem} Let $C$ be a smooth curve given by the vector function
$\myvec{r}(t)$ on $a\leq t\leq b$. Let $f$ be a differentiable function of two
or three variables whose gradient vector $\nabla f$ is continuous on $C$. Then 
$$ \int_C \nabla f\cdot d\myvec{r}  = f(\myvec{r}(b)) - f(\myvec{r}(a)). $$
\end{theorem}
}{% presentation
}{% nopresentation
}{% comments
Mention that this indicates that the line integral in this case is
path-independent. 
}

\content{
\begin{definition} Let $\myvec{F}$ be a vector field. If there exists a function
$f$ such that $\nabla f=\myvec{F}$, we call $\myvec{F}$ a conservative vector
field. 
\end{definition}
}{% presentation
}{% nopresentation
}{% comments
This, along with the previous theorem, means that line integrals of conservative
vector fields are path-independent. 
}

\content{
So, we wish to be able to determine if a vector field is conservative, since
this allows us to easily evaluate line integrals. The following theorem allows
us to do just that. 

\begin{theorem} Let $\myvec{F} = P\myvec{i} + Q\myvec{j}$ be a vector field on
an open simply-connected region $D$. Suppose that $P$ and $Q$ have continuous
first-order partial derivatives and that 
$$ \pd{P}{y} = \pd{Q}{x} $$
on all of $D$. Then $\myvec{F}$ is conservative. 
\end{theorem}
}{% presentation
\vspace{2in}
}{% nopresentation
}{% comments
Briefly go over what it means to be simply connected. 
}

\item $\myvec{F}(x,y) = (3+2xy)\myvec{i}+(x^2-3y^2)\myvec{j}. $
\end{enumerate}
\end{example}
